# ผังการต่อวงจรและการติดตั้งฮาร์ดแวร์ชุดจำลองไม้กั้น (ESP32 Hardware Guide)
## โครงการ: Smart Gate Pass AI — วิทยาลัยการอาชีพองครักษ์ (OICEC)

### 1. รายการอุปกรณ์ชุดจำลอง (ขนาดฐาน 60 × 60 × 10 ซม.) — ครบทั้ง 7 ชิ้น
1. **บอร์ดไมโครคอนโทรลเลอร์**: ESP32 DevKit V1 (ESP-WROOM-32, 30 ขา, ชิป CP2102)
2. **เซอร์โวมอเตอร์ยกไม้กั้น**: TowerPro Micro Servo 9g (SG90) หมุน 0° ถึง 90°
3. **เซนเซอร์วัดระยะป้องกันไม้กั้นตี (Safety Interlock)**: Ultrasonic Sensor HC-SR04
4. **จอแสดงผลสถานะหน้าป้อมยาม**: จอ LCD 16x2 (1602A) พร้อมโมดูลแปลง I2C ด้านหลัง (0x27)
5. **ลำโพงส่งเสียงแจ้งเตือน**: Piezo Buzzer 5V
6. **ชุดไฟแสดงสถานะหน้าไม้กั้น**: หลอด LED สีเขียว และ LED สีแดง (พร้อมตัวต้านทาน 220 โอห์ม)
7. **กล้องสแกนใบหน้า**: USB Webcam Full HD เชื่อมต่อเข้าเครื่องคอมพิวเตอร์ประมวลผล AI

### 3. สเปก API ที่ ESP32 รอรับจากเว็บแอป
* `POST /gate/open` : สั่งยกไม้กั้นขึ้น 90 องศา, เปิดไฟเขียว, แสดงชื่อนักเรียนบนจอ LCD
* `POST /gate/close` : สั่งพับไม้กั้นลง 0 องศา (มีระบบ Safety ตรวจจับ HC-SR04)
* `GET /gate/status` : ส่งสถานะไม้กั้น, มุมองศา และระยะตรวจจับเป็น JSON
